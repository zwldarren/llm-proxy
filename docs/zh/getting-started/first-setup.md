# 首次设置

代理刚装好时还没有任何账户，打开控制台会直接进入 `/setup` 的「创建管理员账户」页面。

## 创建管理员账户

1. 打开 `http://localhost:8080`（或你的部署地址）。
2. 输入用户名和密码。密码必须为 **8–72 个字符**，且至少包含一个大写字母、一个小写
   字母、一个数字和一个特殊字符。
3. 提交后账户以 `admin` 角色创建，并立即登录。

几点说明：

- 设置接口限流为每 IP 每分钟 5 次，而且只能执行一次：管理员已存在时再调用会返回
  `400 setup_complete`。
- 初始密码由你自己设定，不会被强制修改；之后由管理员创建的账户则必须在首次登录时
  改密。

## 接下来做三件事

| 步骤 | 位置 | 原因 |
| --- | --- | --- |
| 1. 添加提供商 | [提供商](/zh/admin/providers) | 没有提供商和模型映射，客户端无模型可用 |
| 2. 检查模型与定价 | [模型与定价](/zh/admin/models) | 客户端按名称请求模型；定价决定成本统计和预算 |
| 3. 创建 API 密钥 | [API 密钥](/zh/admin/api-keys) | 客户端用 API 密钥鉴权，控制台登录态进不了 `/v1/*` |

可选的后续步骤：为虚拟模型 `auto`/`fast`/`best` 打开[智能路由](/zh/api/routing)，
接入 [MCP 服务器](/zh/admin/mcp)，或在
[追踪设置](/zh/admin/observability#tracing)里配置 Langfuse、OpenTelemetry 或
LangSmith。

## 会话与安全

- 控制台会话是有效期 24 小时的 JWT。没有刷新令牌，过期后需要重新登录。
  `POST /api/auth/logout` 会结束会话并停用该会话的游乐场密钥。
- 登录失败按**用户名**累计：连续 5 次失败后锁定 15 分钟（默认值，可在
  [服务器设置](/zh/admin/settings#security-rate-limiting)里调整）。
- JWT 密钥和提供商密钥加密密钥都在首次启动时生成并存入数据库。请保管好数据库：
  数据库丢了，这两个密钥也就没了。见
  [升级与备份](/zh/deployment/upgrades#secrets-what-rotation-breaks)。
